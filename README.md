# Pose & Tenue — galerie locale

1. Télécharger les images et générer le catalogue :

   ```bash
   node download-galleries.mjs
   ```

2. Démarrer le site local :

   ```bash
   python3 -m http.server 8080
   ```

3. Ouvrir http://localhost:8080

Le site fonctionne sans service externe une fois les images téléchargées. Tu peux copier tout le dossier sur un autre ordinateur ou le servir sur ton réseau local.
